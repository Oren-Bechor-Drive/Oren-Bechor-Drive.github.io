# Triage labels

Use these friendly GitHub labels when a skill assigns a triage role. Existing category labels such as `bug` and `accessibility` remain separate.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `Needs review` | Maintainer needs to evaluate the issue. |
| `needs-info` | `Needs more info` | Waiting for more information. |
| `ready-for-agent` | `Ready for Agent` | Fully specified and ready for an agent. |
| `ready-for-human` | `Needs a person` | Requires human implementation. |
| `wontfix` | `Not planned` | Will not be implemented. |

Use the exact label spelling above. Reuse labels by name; create a missing mapped label only as part of an authorized setup or triage operation. Existing labels, including `wontfix`, remain available but are not the canonical triage mapping.
