# Official theory question images - 2026-09-25

The five initial image-dependent questions and five additional roundabout/signal questions use eight distinct Ministry of Transport JPEGs. The [machine-readable media map](theory-media.json) records the final paths, dimensions, alt text and hashes. Each file below was downloaded from the exact image URL in the official open-data question record. The response bytes were saved unchanged, retaining the source filename and extension. No diagram was redrawn, generated, cropped or recompressed.

## Retrieval and rights

Initial requests using Python's default request headers returned HTTP 403. Repeating the original URLs with ordinary browser request headers returned HTTP 200 and `Content-Type: image/jpeg`. The successful headers were `User-Agent: Mozilla/5.0`, `Referer: https://www.gov.il/` and an image Accept header. No alternative publisher or replacement image was used.

Source: Ministry of Transport and Road Safety, [official Hebrew theory dataset](https://data.gov.il/he/datasets/ministry_of_transport/tqhe). Its [official metadata](https://data.gov.il/api/3/action/package_show?id=tqhe) declares `license_id: cc-by`, `license_title: Creative Commons Attribution` and the [CC BY licence reference](https://opendefinition.org/licenses/cc-by/). The metadata does not specify a licence version. These are the original images embedded by that dataset's question records, reused with the question-source attribution. No separate licence for unrelated artwork or third-party explanations is inferred. Course-authored alternative text is identified below and does not imply Ministry endorsement.
