# Interface icons

The user, magnifying-glass, eye, and eye-slash icons are from [Font Awesome Free 7.3.1, Classic Solid](https://github.com/FortAwesome/Font-Awesome/tree/7.3.1/svgs/solid), by Fonticons, Inc. The password controls use the official [eye](https://fontawesome.com/icons/classic/solid/eye) and [eye-slash](https://fontawesome.com/icons/classic/solid/eye-slash) artwork.

The SVG artwork is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Each minified upstream SVG preserves its attribution comment. The complete upstream license is stored at [`../directions/LICENSE.txt`](../directions/LICENSE.txt).

The course and account styles load these local SVGs as CSS masks so they inherit the interface color. The eye and eye-slash files preserve the upstream SVG bytes. No external Font Awesome kit, stylesheet, script or icon font is loaded.
